# Дизайн-система игрового UI ServerCore

**Языки:** [English](../ui-design-system.md) | Русский

Каждая поверхность, которую плагин рисует игроку — тайтлы, экшенбары, чат-блоки, боссбары, tab-лист,
текст, привязанный к миру, — строится из одного тулкита (`plugin/src/.../ui/`). Этот документ —
источник истины для его токенов и правил. Если код и этот документ расходятся, правьте код.

## Направление

Сервер — закрытый сезон survival: приём, ворота, ключи. UI говорит как тихий привратник ночью — сланцевый
камень, латунная фурнитура, сигнальные лампы. Ничего не светится, ничего не продаёт.

- **Характер:** спокойный, точный, чуть тёплый.
- **Мир:** привратницкая ночью — обсидиановый сланец, латунь, свет лампы.
- **Подпись:** латунный знак `◆` и рейка `┃`, открывающая каждый системный блок в чате. Если у сообщения
  нет ни того, ни другого — это не системное сообщение.

## Палитра («обсидиан и латунь»)

Все цвета живут константами Kotlin в `ui/Theme.kt`. Шаблоны локали никогда не используют ванильные имена
цветов — только теги темы, зарегистрированные там. Сменить бренд — значит изменить один файл.

| Токен | Hex | Роль |
|---|---|---|
| `PRIMARY` | `#E9E4D8` | пергамент — основной текст |
| `SECONDARY` | `#ADA79A` | вспомогательный текст |
| `MUTED` | `#6E6A62` | мета, ремарки; ≥3:1 на фоне чата |
| `HAIRLINE` | `#3C3F45` | линейки, рейки, отработанные сегменты бара — никогда текст |
| `GOLD` | `#D9A441` | акцент. знак бренда, ключевые числа, единственная яркая вещь |
| `GOLD_DIM` | `#8A6A2B` | линейки, принадлежащие бренду |
| `OK` | `#7CB874` | состояния успеха |
| `WARN` | `#D98F4A` | состояния предупреждения |
| `DANGER` | `#D2655C` | сбой, истечение, отказ |
| `INFO` | `#8FA8BF` | информационные баннеры |

Рядом с палитрой живёт один нетекстовый токен: `HOLOGRAM_BACKING_ARGB` (`#90141618`) — полупрозрачный
обсидиан за текстом `TextDisplay`, привязанным к миру.

Правила:

- Роли, несущие текст (`PRIMARY`, `SECONDARY`, `GOLD`, семантические), покрыты unit-тестами на 4.5:1 на
  почти чёрной поверхности чата; `MUTED` проходит 3:1.
- Один акцент на поверхность. Золото помечает то, что важно — код, число, заголовок — никогда целые
  абзацы и никогда как заливку фона.
- Семантические цвета несут только смысл. Никакого декоративного зелёного.

Алиасы тегов MiniMessage: `<primary>`, `<secondary>`, `<muted>`, `<hairline>`, `<gold>`, `<brand>`
(= gold), `<ok>`, `<warn>`, `<danger>`, `<info>`.

## Типографика и геометрия

Набор глифов Minecraft фиксирован, поэтому «шрифт» здесь означает вес через цвет, плотность и дисциплину
маркеров:

- **Тайтлы:** одно-два слова в акценте или основном цвете, строчными как в предложении, без завершающей
  пунктуации. Подзаголовок несёт само предложение в `SECONDARY`.
- **Чат-блоки:** строки содержимого стоят за рейкой `┃ `; линейки `─` открывают и закрывают блок
  (`FRAME_WIDTH = 40` глифов). Одна мысль на строку. Блоки никогда не длиннее ~6 строк — всё, что
  длиннее, принадлежит предмету или команде.
- **Однострочники в чате:** одиночное системное уведомление сохраняет рейку и отбрасывает линейки
  (`UiFx.railLine`). Если нет ни рейки, ни `◆` — это не системное сообщение.
- **Экшенбар:** одна строка, ≤60 глифов, переотправляется по расписанию, когда выражает непрерывное
  состояние (пульс чередует маркеры `▸`/`▹`).
- **Боссбар:** только процессы со временем. Оверлей `PROGRESS`, жёлтый в спокойном состоянии, красный
  после последней четверти.
- **Tab-лист:** один заголовок, один подвал, окружающая идентичность, никаких статов.
- **Голограммы (`TextDisplay`):** только информация, привязанная к миру, сланцевая полупрозрачная
  подложка, непостоянные, с автоистечением.

Тайминг — часть системы, а не выбор отдельного экрана (`UiFx`): 100 мс появление, 2600 мс удержание,
300 мс исчезновение. Приветствие может держаться 3200 мс, потому что это единственный заголовок, который
получает гость; тик секундного отсчёта держится 950 мс, чтобы хвост затухания перетёк в следующий кадр.
Экраны кика — один многострочный компонент, никогда не «напечатать строки, потом кикнуть».

## Правила выбора поверхности

Спрашивайте по порядку:

1. **Игроку нужно будет прокрутить чат обратно к этому?** → чат-блок (карточка/рамка).
2. **Это смена состояния, которая может прервать?** → тайтл.
3. **Это непрерывное временное состояние?** → экшенбар, переотправляемый по расписанию.
4. **Время заканчивается?** → боссбар (плюс тики тайтла за последние пять секунд).
5. **Это принадлежит месту в мире?** → голограмма.
6. **Это принадлежит сессии в целом?** → tab-лист.

Две поверхности могут сочетаться (тайтл объявляет, карточка объясняет), три одновременно — никогда.

## Потоки (Folia)

- Всё планирование, принадлежащее игроку, идёт через его `EntityScheduler` (хелперы `UiScheduler`).
  Никаких предположений о главном потоке нигде.
- **Каждая отправка переходит**, включая «безобидные»: `Player.uiNow` для одноразовых записей,
  `uiDelayed`/`uiRepeat` для поэтапных. Вызывающими сообщения могут быть асинхронное событие чата,
  колбэк WS или осевший хук координатора, поэтому поверхность никогда не отправляет из того места, откуда
  её случайно позвали. Показ/скрытие боссбара — состояние игрока и тоже переходит, что делает
  `Countdown.cancel()` безопасным из любого потока.
- Размещение в мире (спавн/деспавн голограммы) выполняется в `RegionScheduler`, которому принадлежит
  точка; удаление сущности — в планировщике самой сущности.
- Пуши локали приходят в потоке WS: парсите вне горячего пути, подменяйте хранилище атомарно, затем
  сохраняйте на диск.

## Правила текста (anti-slop)

- Никаких восклицательных знаков. Никаких точек в конце коротких строк. Никаких «Добро пожаловать на
  сервер».
- Заголовки в шаблонах строчными (первый глиф может быть заглавным, когда строка начинает
  предложение — здешний RU-текст использует строчные заголовки для системных блоков).
- Называйте вещь, а не чувство: «код: 123-456 — подтверди в Telegram-боте», а не «Вы почти у цели!».
- Числа приходят от вызывающего как плейсхолдеры, никогда не вшиты в шаблоны.

## Локализация

Одно хранилище на рантайме, без второго слоя:

- **Каноническое хранилище локали** (`locale/LocaleService.kt`, семена —
  `plugin/src/main/resources/locales/ru.yml` + `locales/en.yml`). Каждая строка, видимая игроку, живёт
  здесь: поверхности тулкита (tab-лист, приветствие, окно авторизации, отсчёт) и текст фич (жизненный
  цикл гостя, ответы наблюдения, отказы защиты, отладочная выдача прав, `placeholders.*`). `guest.lang`
  выбирает активный язык; ключ, которого в нём нет, откатывается к английской базе, а ключ, которого нет
  нигде, рендерится сам собой как ключ.
- Шаблоны приходят **целыми файлами**, которые backend пушит по WS как `LOCALE_PUSH` (см.
  `docs/websocket-protocol.md`); плагин валидирует файл, атомарно подменяет хранилище для этого языка,
  подтверждает через `LOCALE_ACK` и сохраняет в `plugins/ServerCore/locales/<lang>.yml`, который на старте
  важнее семени. Сегодня backend отдаёт канонический бандл `ru`; `en` едет в jar плагина и может
  пушиться по тому же каналу.
- `util/I18n.kt` — тонкий фасад над сервисом, оставленный, чтобы места вызова фич по-прежнему говорили
  `text`/`component`/`components`. Он не владеет ни строками, ни файлами.
- Обе локали используют одни теги темы; ванильные имена цветов запрещены, и тест роняет сборку на них.
  Исключение — `placeholders.*`: эти значения потребляются PlaceholderAPI как простой legacy-текст,
  поэтому они не несут разметки вовсе.
- Значения плейсхолдеров экранируются для MiniMessage при инъекции (`LocaleService.component` /
  `Theme.render`); фича никогда не склеивает имя игрока с шаблоном. Присланные шаблоны доверяются ровно
  настолько, насколько парсится их yaml.
- `ResourceMarkupTest` парсит каждый вшитый шаблон в строгом MiniMessage (неизвестные и незакрытые теги
  падают), отклоняет ванильные цвета, legacy `§`, пустые пары тегов и удвоенные пробелы.
  `MessagesResourcesTest` держит паритет ключей ru/en, список ключей, которые код реально рендерит, и
  проверяет, что старый плоский слой `messages_*.yml` исчез.

## Карта тулкита

| Часть | Файл | Назначение |
|---|---|---|
| Токены темы + резолвер тегов | `ui/Theme.kt` | палитра, декоративные глифы, ширина рамки, подложка голограммы |
| Движок плейсхолдеров | `ui/Placeholders.kt` | подстановка `{name}` с экранированием |
| Поверхности | `ui/UiFx.kt` | примитивы тайтла/экшенбара/чат-рамки/рейки/tab-листа |
| Форматирование отсчёта | `ui/CountdownRenderer.kt` | чистая, покрытая тестами логика бара и часов |
| Рантайм отсчёта | `ui/Countdown.kt` | боссбар + тики тайтла в EntityScheduler |
| Компоненты | `ui/Components.kt` | `UiKit`: title, actionBar, statusCard, banner, tabList, countdown |
| Голограммы | `ui/Holograms.kt` | истекающий `TextDisplay`, Folia-безопасный |
| Планирование | `ui/UiScheduler.kt` | обёртки `uiNow`/`uiDelayed`/`uiRepeat` над планировщиком сущности |
| Локаль | `locale/*` | хранилище, сервис, WS DTO |
| Фасад текста фич | `util/I18n.kt` | тонкая обёртка `text`/`component` над сервисом локали |
| Личность при входе | `boot/JoinFlowListener.kt` | tab-лист к прибытию |
