# Инфо-бары сервера

**Языки:** [English](../bars.md) | Русский

Живое состояние сервера как персональный переключатель: боссбар (или строка в экшенбаре), который игрок
включает сам для себя. Каждый бар опционален — никто не обязан смотреть на метрики — и выбор
запоминается между перезаходами.

```
◆ RAM 3.2 GB / 8.0 GB (40%)
◆ TPS 19.9 · region 6,-1 · server 20.0
◆ MSPT 12.5 ms · p95 18.0 ms
◆ Online 7/60 (12%)
◆ world 14:32 · 68% · clear
◆ Network 3/3 servers · 7 online · 1 offline
```

## Команды

| Команда | Право | Описание |
|---|---|---|
| `/rambar` | `servercore.bars.ram` | Занятая куча против максимальной кучи JVM |
| `/tpsbar` | `servercore.bars.tps` | TPS региона, в котором стоит игрок |
| `/msptbar` | `servercore.bars.mspt` | Время тика того же региона |
| `/playersbar` | `servercore.bars.players` | Игроки онлайн против лимита слотов |
| `/worldbar` | `servercore.bars.world` | Мир игрока, его часы и погода |
| `/netbar` | `servercore.bars.net` | Вся сеть: отвечающие серверы, игроки, мёртвые серверы |

Без аргументов команда переключает бар для себя. Каждая команда принимает и цель:

```
/rambar              toggles your own ram bar
/rambar Steve        toggles Steve's bar (needs servercore.bars.ram.other)
/rambar all          toggles every online player (needs the .other node)
```

Нода `.other` нужна для любой формы с целью, включая `all`. Ники дополняются табом; литерал `all` никогда
не трактуется как ник игрока. Из консоли форма с целью тоже работает.

Включение бара заменяет тот бар, который у игрока был на той же поверхности — один боссбар на игрока,
поэтому после `/rambar`, а затем `/tpsbar` останется TPS-бар. Бары хранятся по игрокам в
`plugins/ServerCore/bars.json`; удаление этого файла просто сбрасывает всех в «выкл».

## Бар сети

`/netbar` — единственный бар, данные которого приходят не из этого процесса. Backend и так отслеживает
heartbeat каждого игрового сервера; он строит агрегат и отправляет его всем подключённым серверам кадром
`NETWORK_SNAPSHOT` сразу после того, как heartbeat обновил справочник (без отдельного таймера, не чаще
одного пуша в секунду). Плагин кеширует агрегат, а бар его отрисовывает — поэтому на любом сервере сети
это работает без опроса.

Три состояния, все честные:

- **свежий агрегат** — `3/3 servers · 7 online`. Заполнение = отвечающие серверы / известные серверы,
  зелёный, когда отвечают все.
- **сервер замолчал** — в строке появляется `· 1 offline`, цвет падает. Сервер считается «молчащим»,
  когда его последний heartbeat старше `bars.net.stale-after-ms`, отсчитанного от момента прихода кадра
  плюс возраст, который у него уже был.
- **агрегата ещё нет** — backend лежит, никогда не был доступен или собран из сборки без этого пуша. Бар
  откатывается на этот сервер в одиночку: `1/1 servers` с локальным счётчиком. Он никогда не показывает
  прочерк и никогда не выдумывает флот.

Две вещи, которые стоит знать:

- **«всего» — это серверы, которые backend видел.** Сервер, простаивавший с момента последнего рестарта
  backend, отсутствует в справочнике и не учитывается, пока не подключится хоть раз.
- **игроки** — сумма backend по всем известным серверам, поэтому молчащий сервер вносит последнее
  присланное им число. Сегмент `offline` говорит, что число не полностью живое.

## Конфигурация

```yaml
bars:
  enabled: true                  # master switch: off = no rendering, no /bar commands
  update-interval-ticks: 20      # refresh cadence, 20 ticks = 1s, clamped 1..200
  display: bossbar               # bossbar | actionbar
  ram:
    enabled: true
    good: 60                     # heap fill percent at or below this is healthy
    medium: 80                   # above this is critical
  tps:
    enabled: true
    good: 18.0                   # TPS at or above this is healthy
    medium: 15.0                 # below this is critical
  mspt:
    enabled: true
    good: 40.0                   # tick time in ms at or below this is healthy
    medium: 50.0                 # above this is the 20 TPS budget
  players:
    enabled: true
  world:
    enabled: true
    show-weather: true           # false = world and clock only
  net:
    enabled: true
    stale-after-ms: 45000        # heartbeat age that counts as offline
```

Замечания:

- `update-interval-ticks` зажимается в `1..200`; перепутанная пара `good`/`medium` выстраивается обратно
  по порядку с предупреждением, а не инвертирует цвета молча.
- `net.stale-after-ms` по умолчанию равен **трём интервалам heartbeat** из
  `backend.heartbeat-interval-seconds` (15 с × 3 = 45 с). Если задать меньше одного интервала, серверы
  будут мигать офлайном между heartbeat'ами; загрузчик предупреждает и зажимает значение в
  `5000..600000`.
- У каждого бара свой `enabled`. Выключенный бар теряет и свою команду, поэтому игроки никогда не видят
  команду, которая не может сработать.
- Поверхность глобальная, а не для каждого бара: `bossbar` рисует полосу прогресса над хотбаром,
  `actionbar` пишет одну строку, которая затухает и переотправляется на следующем обновлении.

## Права

| Нода | Значение |
|---|---|
| `servercore.bars.ram` / `.tps` / `.mspt` / `.players` / `.world` / `.net` | Переключить этот бар себе |
| любая из них плюс `.other` (например, `servercore.bars.ram.other`) | Переключить этот бар другому игроку или всем (`all`) |

Источник прав — LuckPerms; статус оператора не учитывается никогда. Разумное разделение: `/netbar` и
`/rambar` модераторам, всё остальное админам, `/playersbar` и `/worldbar` всем.

## Замечания по Folia — что эти числа на самом деле значат

В Folia нет серверного тика. Единого «TPS сервера» не существует, и бар, который бы его заявлял, врал
бы, поэтому плагин явно обозначает область:

- **`/tpsbar` показывает регион игрока**, прочитанный через `Server.getRegionTPS(location)` в планировщике
  сущности самого игрока — задача, обновляющая бар, и так выполняется в региональном потоке, которому он
  принадлежит. В заголовке печатается пара чанков (`region 6,-1`) и окно в одну минуту. Серверный агрегат
  идёт рядом как `server <tps>` для сравнения. Когда точкой не владеет ни один регион (незагруженный
  чанк, регион в процессе разделения), значение региона — `—`, а для цвета берётся агрегат.
- **`/msptbar` показывает пятисекундный отчёт тиков того региона.** У Folia нет API MSPT по точке (PR
  в апстриме всё ещё открыт), но `getAverageTickTime()` в Folia привязан к региону: из регионального
  потока он возвращает отчёт этого региона, из любого другого места бросает исключение. Задача бара по
  построению региональная, так что чтение законно и reflection не нужен. `p95` считается по последней
  минуте этих пятисекундных средних — это значит «пятисекундное среднее региона было не меньше x в 5 %
  последней минуты», а не «5 % отдельных тиков заняли x».
- **Фолбэк по темпу.** Если отчёт региона недоступен, бар измеряет зазор между своими собственными
  запусками обновления. Это сигнал темпа и перегрузки с полом в 50 мс, а не процессорное время; при
  переключении плагин пишет одно предупреждение.
- **`/rambar` и `/worldbar` — факты процесса и мира**, а не региона. Кучу читает один асинхронный
  сэмплер, и каждый бар читает снапшот; часы и погоду мира читает региональный поток игрока.
- **Два игрока в разных регионах видят разный TPS/MSPT.** Это правильно, а не баг.

## PlaceholderAPI

Когда PlaceholderAPI установлен, `%servercore_…%` отдаёт значения баров, чтобы скорборды и tab-листы
могли их переиспользовать. Значения читаются из того же слоя снапшотов, из которого рисуют бары — никогда
не считаются в потоке спрашивающего, никогда не блокируют и отстают максимум на один интервал обновления
плюс окно мемоизации плейсхолдеров (`placeholders.cache-ttl-milliseconds`, по умолчанию 2 с).

| Плейсхолдер | Значение |
|---|---|
| `%servercore_bar_ram%` | Процент заполнения кучи, например `42` |
| `%servercore_bar_tps%` | TPS с одним знаком, например `19.8` |
| `%servercore_bar_mspt%` | Миллисекунды с одним знаком, например `38.4` |
| `%servercore_bar_players%` | Число игроков онлайн, например `7` |
| `%servercore_bar_net%` | Отвечающие серверы / известные серверы, например `3/3` |

Какое чтение отдаёт плейсхолдер:

- `ram`, `players`, `net` одинаковы для всех. Они сэмплируются каждый интервал обновления даже при
  выключенных барах, так что скорборд никогда не зависит от того, носит кто-то бар или нет.
- `tps` отвечает чтением региона самого спрашивающего, пока у него включён TPS-бар, иначе серверным
  агрегатом. `mspt` отвечает чтением региона спрашивающего, иначе последним региональным сэмплом этого
  сервера — серверного MSPT для фолбэка просто нет.
- Если сэмпла нет вовсе (плагин только стартовал, Folia только что переработала регион), значением будет
  настроенный `placeholders.unknown-value` (по умолчанию `unknown`). Отличайте его от настоящего нуля в
  своей вёрстке.

Пример строки скорборда (любой плагин скорбордов, понимающий PlaceholderAPI; завершающий `%` после
плейсхолдера ram — это знак процента):

```text
&7tps &f%servercore_bar_tps%  &7ram &f%servercore_bar_ram%%  &7players &f%servercore_bar_players%
```

Пример заголовка или подвала TAB:

```text
%servercore_bar_net% servers · %servercore_bar_players% online
```

Держите интервал обновления потребляющего плагина не меньше `bars.update-interval-ticks` (1 с). Более
частые запросы лишь перечитывают то же кешированное значение.

## Как выключить

- `bars.enabled: false` — ни отрисовки, ни команд, ни сэмплирования. Плейсхолдеры `%servercore_bar_*%`
  отдают неизвестное значение.
- `bars.display: actionbar` — те же бары, но без занятия слота боссбара (полезно, когда боссбарами
  владеет другой плагин).
- `bars.<bar>.enabled: false` — убрать отдельный бар и его команду.
